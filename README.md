# Timesheet Economista Chefe

Dashboard de atividades (Calls Cliente, Eventos, Captacao/Boleta e Imprensa) para apresentacao interna.

Arquivos:
- timesheet-economista-chefe.html: dashboard estatico, visao empresa, somente leitura.
- timesheet-data.json: base de dados das atividades.
- render_dashboard.py: gera o HTML a partir do JSON.
